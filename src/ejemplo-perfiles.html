Qué muestra esta página

  • Un perfil por rol: superadmin, administrador, docente, estudiante y tutor, cada uno con indicadores, pestañas y acciones propios.
  • Contexto: AU.setContext cambia usuario, institución, roles y permisos; data-au-bind pone los textos y data-au-can muestra solo lo permitido.
{{#> components/how-to title="Cómo se usa"}} {{{{code}}}}

// El contexto sale del servidor o de #au-context; aquí se cambia para la demostración AU.setContext({ user, institution, roles: ['teacher'], permissions: ['notas.registrar'] }); AU.can('notas.registrar'); // true (solo oculta botones: no protege) {{{{/code}}}} {{/components/how-to}}
