Arrastre una tarjeta a otra columna, o use las flechas de la tarjeta con el teclado.

Qué muestra esta página

  • Arrastrar: AU.dragSort con un mismo group en las tres listas permite pasar tarjetas entre columnas; SortableJS se carga solo al abrir la página.
  • Teclado y lectores de pantalla: arrastrar no es accesible por sí solo, por eso cada tarjeta trae botones «Mover a…» (Tab y Enter). Cada movimiento se anuncia con su posición y el foco sigue a la tarjeta.
  • Conteos: el número de cada columna se recalcula tras cada movimiento.

// Arrastre entre columnas y alternativa para teclado (solo con la fachada AU) await AU.dragSort(lista, { group: 'tablero', draggable: '.au-kanban-card', onEnd: (e) => mover(e.item.dataset.id, e.to.dataset.col, e.newIndex) }); // Botón por tarjeta: data-tab-move="revision" y aria-label="Mover «título» a En revisión" {{{{/code}}}} {{/components/how-to}}
