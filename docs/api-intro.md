# Aula RD — Referencia técnica del JavaScript

Generada con JSDoc desde `src/js/`. La guía de uso para páginas está en `docs/04-api-au.md`; aquí está el detalle de cada módulo, función, parámetro y tipo.

- **facade** — construye `window.AU`.
- **core/** — eventos, registro de componentes, tema, HTTP, plantillas, contexto, errores, almacenamiento.
- **helpers/** — funciones puras (formato es-DO, validadores dominicanos, esquemas Zod, sanitización, estados, archivos, configuración de gráficos).
- **adapters/** — integraciones con carga diferida (Chart.js, DataTables, Choices, Flatpickr, FullCalendar, Quill, SheetJS, JsBarcode, QR, Signature Pad, Sortable).
- **components/** — comportamientos declarativos `data-au-*` y diálogos.
